🚶 Core Journey Through the System

1. First visit — Intro animation (bunny draw + "Hello, this is Buno") → Premise → Budget input → saved to localStorage → Zone tab
2. Returning visit — localStorage checked → sandbox loads → Zone Engine calculates → health bar animates → human note displays
3. Log cash expense — Activity tab → fill form → validate → save to localStorage → feed re-renders with bounce → zone recalculates → health bar morphs
4. Danger exceeded — pct ≤ 0% → DANGER modal mounts → GSAP shake → "Budget is empty now" → dismiss → app continues

⚙️ Zone Engine Signature

function calculateZone( budget: number, transactions: Transaction[] ): { remaining: number; pct: number; zone: 'safe' | 'cautious' | 'danger' | 'depleted'; note: string; }

Pure function — no side effects. Easy to test and understand. This is the kernel.

💡 Learning Moment: React + GSAP

React re-renders the DOM declaratively ("show this now"). GSAP animates imperatively ("move from here to here over 0.5s"). These coexist but require careful wiring — typically useEffect + gsap.to() on a ref. This is the core technical learning moment of the build. We'll explore it with a concrete example during 5-build.
