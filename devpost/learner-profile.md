# Learner Profile

## Initial Idea
Rebuild **Buno** — a research-backed budgeting app based on "The Budgeting App Trap: When Spending Information Backfires." Core insight: exact remaining balances trigger "permission to spend" behavior; Buno replaces numeric precision with qualitative spending windows (e.g., "safer" / "watchful") and behavioral nudges. They previously built an MVP (Next.js/React/TypeScript) for a Devpost hackathon but want to redo it with better UI and a stronger pitch. Deterministic budget engine + separate qualitative insight layer.

## Demonstrated Technical and Agent Experience
Built websites with AI 3–4 times. Recent Devpost video gave them a clearer structure for hackathon projects. Comfortable with AI-assisted coding but has experienced "bunch of code generated, debugging with AI, but wouldn't know the exact mechanics."
> Evidence: "I'd have a bunch of code generated and I'd be debugging it with code with AI multiple times, but I wouldn't know the exact mechanics of it."

## Planning-Workflow Experience
**New** to plan-first / spec-driven workflow. The Devpost video was their first exposure to a structured planning approach for hackathons.
> Evidence: "only after watching Devpost video on how to work with the same, we really got to know a better structure, I would say, for building a platform for a hackathon."

## Desired Learning Outcome
Learn to build websites with AI that have a "personalized human's touch" and **understand the architecture/mechanics of every part** — not line-by-line, but the main ideas and effort behind them. Wants to be able to work on the app technically themselves, not just have the idea.
> Evidence: "I want to effectively learn how to make websites with AI, but it should have that personalized human's touch and I should know how each and every part of the code works... I want to also understand how technically the app and like how to work on the app myself."
